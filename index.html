About

I learn by building, and I document everything.

Every project here runs in my own home lab or AWS account: Proxmox and VMware ESXi hosts, FortiGate and Cisco virtual appliances, a Windows Server domain, and cloud workloads on AWS. I build each one end to end, troubleshoot it until it works, and write it up so someone else could rebuild it.

Enterprise networking

Routing (OSPF, BGP), VLAN design, NAT, firewall policy, IPsec VPNs and SD-WAN failover across FortiGate, Cisco and UniFi.

Systems & infrastructure

Windows Server, Active Directory, DNS and DHCP, Exchange, virtualisation on ESXi and Proxmox, and backup with Veeam.

Cloud & DevOps

AWS networking, containers on ECS and EKS, Infrastructure as Code with Terraform, CI/CD pipelines and observability.

Security

Least-privilege access, network segmentation, and hands-on Active Directory attack paths to understand how to defend them.
